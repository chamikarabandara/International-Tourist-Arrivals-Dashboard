
# International Tourist Arrivals Dashboard

## Project Overview
This project analyses international tourist arrivals in Sri Lanka using Microsoft Power BI. It explores yearly trends, monthly seasonal patterns, and the main tourist source markets.

## Objectives
- Analyse tourist arrivals by year.
- Identify monthly tourism trends and seasonal variations.
- Identify the top 10 tourist source countries.
- Support data-driven tourism planning and marketing.

## Tools and Technologies
- Microsoft Power BI Desktop
- Power Query
- CSV datasets
- Data visualization and interactive filtering

## Dashboard Features
- Total Tourist Arrivals KPI
- Tourist Arrivals by Year
- Top 10 Countries by Tourist Arrivals
- Monthly Tourist Arrivals Trend
- Interactive Year and Country slicers

## Project Structure
- `data/` - Source CSV datasets
- `dashboard/` - Power BI dashboard file
- `images/` - Dashboard screenshots

## Key Insights
- Tourist arrivals increased from 2022 to 2025 in the analysed dataset.
- India was the leading source market.
- Tourist arrivals showed seasonal variations.
- The dashboard supports filtering by year and country.

Note: The 2026 data may cover only part of the year and should not be compared directly with complete years.

## How to Use
1. Download or clone this repository.
2. Open the `.pbix` file using Power BI Desktop.
3. If required, update the CSV data source paths.
4. Refresh the data and explore the dashboard using the slicers.

## Data Sources
Sri Lanka Tourism Development Authority (SLTDA) tourist arrival statistics.
